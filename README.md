# Private 5G Network Simulation

## Objective
Build and validate a software-based 5G Standalone network.

## Initial architecture
- Open5GS: 5G Core
- UERANSIM: simulated gNB and UE
- Linux: networking, routing, packet capture, and diagnostics

## Initial milestones
1. Validate the host environment.
2. Install and verify Open5GS.
3. Build UERANSIM.
4. Register a simulated UE.
5. Establish a PDU session.
6. Validate user-plane connectivity.
7. Capture and analyze packets.
8. Document failures and recovery procedures.

## Reproducibility
All project-owned configurations, commands, tests, and results
should be documented and version-controlled.
